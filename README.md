# Семейное меню — прототип для Windows

Python 3.11+ с Tkinter (в официальном установщике Python для Windows включён по умолчанию). Внешние зависимости не нужны.

Запуск из папки проекта:

```bat
py app.py
```

Проверки: `python -m unittest discover -s tests -v`.

Рецепты хранятся в `%LOCALAPPDATA%\NJ-cooking\recipes.json`.

## Возможности

- Извлечение текста `.docx`, включая документ с несколькими рецептами. Разделение на рецепты и перенос продуктов в поля пока ручные. Старый формат `.doc` не поддерживается.
- Сохранение рецептов с исходным числом порций, подтверждёнными ккал на порцию и ингредиентами вида `Рис; 400; г`.
- 7 дней, 3 приёма пищи; число людей и порций на человека за приём пищи.
- Калории на человека в сутки с абсолютным допуском ± ккал.
- Исключения и обязательное использование каждого желаемого продукта хотя бы раз за неделю. Сопоставление по подстроке без морфологии: выбирайте названия внимательно. Это не медицинская проверка аллергенов.
- Количества на блюдо, день, неделю; точное объединение кг/г и л/мл. Штуки в граммы не переводятся.
- Экспорт меню и продуктов в текст.

Подбор использует ограниченный случайный поиск: иногда может не найти существующее решение. Блюда могут повторяться, категории завтрака/обеда/ужина пока не ограничиваются. Пожелания обеспечивают наличие продукта, но не учитывают количество остатка.
