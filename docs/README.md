# Руководство пользователя

- [Читать на GitHub](USER_GUIDE_RU.md).
- [PDF](USER_GUIDE_RU.pdf) — для скачивания, просмотра и печати; альбомный A4, оглавление, закладки и номера страниц.
- [HTML](USER_GUIDE_RU.html) — один файл со встроенными изображениями, открывается в браузере без интернета. Скачайте сам файл или откройте его из распакованного проекта; просмотр HTML-кода на GitHub не запускает страницу.

Руководство соответствует версии 0.8.1. Все 13 снимков получены из настоящего интерфейса на временной учебной базе. Красные рамки и номера — временные Tk-виджеты, добавленные только при съёмке, а не элементы обычной программы. На Windows оформление отличается от использованной Linux-темы.

## Обновление документации

Исходный текст — `USER_GUIDE_RU.md`, оформление — `guide.css`. Данные пользователя не используются. Инструменты ниже нужны только для документации; приложение по-прежнему не требует сторонних Python-библиотек.

1. Для новых снимков нужен Linux с X11, установленными Tcl/Tk, Noto Sans и ImageMagick (`import`). Из корня проекта:

   ```sh
   DISPLAY=:99 /usr/bin/python3 docs/tools/capture_guide.py
   ```

2. Для HTML/PDF нужны Pandoc, Python Playwright и Chromium. Из корня проекта:

   ```sh
   python docs/tools/build_guide.py
   ```

   При необходимости укажите путь к Chromium в переменной `GUIDE_CHROMIUM`. Изображения встраиваются в HTML; при сборке проверяется их загрузка. PDF создаётся из того же HTML.

3. Проверьте подписи, ссылки, PDF и соответствие номеров кнопок. Обновите версию и дату в тексте и инструменте сборки при изменении интерфейса. В коммит должны войти исходник, снимки и обновлённые HTML/PDF.
