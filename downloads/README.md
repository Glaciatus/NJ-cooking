# База русских рецептов

[Скачать архив с 13 703 рецептами](https://github.com/Glaciatus/NJ-cooking/raw/refs/heads/main/downloads/NJ-Cooking-13703-recipes.zip)

Это дополнительный пакет данных. Исходники программы остаются в корне репозитория.

1. Закройте NJ-Cooking.
2. Скачайте и распакуйте архив в отдельную папку.
3. Запустите `IMPORT_WINDOWS.bat` (нужен Python с Python Launcher).
4. После сообщения `Done` откройте приложение.

Загрузчик объединяет базу с вашими рецептами и сохраняет резервную копию прежнего файла. Полная инструкция находится внутри архива.

В базе отсутствует готовое КБЖУ; число порций указано не у всех рецептов. Импортированные записи требуют проверки перед подбором меню. Источники и имеющиеся ссылки на фото/видео сохранены.
